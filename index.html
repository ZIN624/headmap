    ヘッドを変える

    描いた図は新しいヘッドの同じ位置に移ります。元のヘッドに戻せば元どおりです。

    使い方

    2種類のカット図

    3D ヘッド：頭に直接描いて、どの角度にも回せます。2D 5方向：左側面・右側面・上・正面・背面の5枚の平面図で、下絵はヘッド 2 から作ります。どちらも複数のステップを作れます。3D は新規作成時にヘッド 4 を使います。ヘッドを変えるときは右上の目のボタンで選びます（描いた図も一緒に移ります）。

    2D の描き方

    • 一覧で方向をタップすると描けます。上の「左 右 上 前 後」で方向を切り替えます。2本指で拡大縮小・移動。パソコンはホイールで拡大縮小、右ドラッグで移動。
    • 線：直線・矢印・曲線（直線を引いてから真ん中の四角をドラッグして曲げる）・曲線矢印・折れ線。水平・垂直・45° に近いと自動でそろいます。
    • スナップ：線の端が15ポイント・ほかの線の端・頭の外枠に吸い付きます。並んだ線の端には青い補助線が出ます。
    • ミラー：左右対称の方向では片側に描くと反対側にも描きます。左側面に描くと右側面にも描きます。あとで片側を直すと反対側も変わります。
    • 線を整える：近い線の端同士をつなぎ、頭の外枠やほかの線に近い端はちょうど届くまで伸ばします。
    • ⋯ メニュー：ブロッキングのテンプレート（正中線・イヤーツーイヤー・4ブロック・Uセクション・前髪トライアングル）、片側ミラー、自分の写真を下絵にする、この方向のメモ。
    • 線を選択：本体をドラッグで移動、丸で端を変更、四角で曲がり具合や大きさを変更、円で回転。キーボード：矢印キーで微調整、Ctrl＋D で複製、Delete で削除。

    よく使う描き方

    • 実線：ブロッキング・作業範囲。細い線：スライス。
    • 矢印：引き出す方向。斜め上の矢印＝リフト。
    • 破線：カットライン・カットの形。
    • 点：オンベースの位置。道具アイコン：どの技法で切るか。

    プレビューと書き出し

    プレビューでは線が1本ずつ描かれます（平行な線は同時）。速さを選んだり、最初から全部再生したりできます。プレビュー右上のダウンロードボタンで、見ている画面を画像で保存できます。ほかの書き出しはタイトルのメニューにあります：PNG・5方向まとめ・PDF・アニメーション動画・SNS用カルーセル画像・JSON。

    図の保存場所

    図はこのブラウザの中に保存され（写真はブラウザのデータベースに別に保存）、どのサーバーにも送られません。ブラウザのデータを消すと消えるので、大事な図は JSON で書き出してバックアップしてください。iPhone・iPad の Safari で直接開いたサイトは、7日間続けて開かないと消えることがあります：「ホーム画面に追加」してから使ってください。

    その他

    iPhone・iPad：Safari で直接開いたサイトは、7日間続けて開かないと保存した図が消えることがあります。「ホーム画面に追加」してから使い、大事な図は定期的に書き出してください。

    このアプリとライセンス

    カット図：3D のヘッドや5方向の平面図に、点・線・面・パネルを描きます。描いた図はこのブラウザの中にだけ保存されます。

    このアプリのプログラムは AGPL-3.0 ライセンスで公開しています：この日本語版のソースコード（ライセンス全文）。元のアプリ headmap（繁体字中国語）を日本語化したものです。ヘッドとライブラリは、下に書いたそれぞれのライセンスに従います。

    iPhone・iPad：Safari で直接開いたサイトは、7日間続けて開かないと、ブラウザが保存した図を消すことがあります。共有メニューの「ホーム画面に追加」から開き、大事な図は定期的に JSON で書き出してください。
